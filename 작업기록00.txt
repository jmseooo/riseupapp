이번 세션에서 한 작업
========================

목표
----
Figma로 디자인한 RiseUp 앱을 실제 iOS 앱으로 구현


만든 파일들
-----------

[디자인 시스템]
- DesignTokens.swift     : Figma의 색상, 폰트, 여백 수치를 코드로 변환
- WeatherBackground.swift: Figma의 그라디언트 배경을 SwiftUI로 구현

[화면 (Views)]
- HomeView.swift         : 메인 화면. 일출 시간 표시 + 알람 토글
- OnboardingView.swift   : 첫 실행 화면. 위치 권한 요청
- SettingsView.swift     : 설정 화면. 알람 시간 오프셋 조절
- PersonalView.swift     : 개인 화면. 일출 스파크라인 차트 + TODO


알람 작동 방식
--------------

앱 최초 실행
  → 위치 권한 허용 → 내 위치 기반 일출 시간 계산
  → 홈 화면에서 내일 일출 시간 확인
  → 토글 ON → 알람 예약

알람 울림
  → 다음 날 일출 시간으로 자동 재예약
  → 반복
