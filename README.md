# Suners

내 위치의 **일출 시간에 맞춰 깨워주는** iOS 알람 앱

서울여자대학교 첨단미디어디자인전공 졸업작품

---

## 소개

알람을 몇 시에 맞출지 고민하는 대신, **오늘 해가 뜨는 시간**에 맞춰 깨워줍니다.

일출 시각은 계절과 위치에 따라 매일 조금씩 달라집니다. Suners는 현재 위치를 기준으로 그날의 일출 시각을 계산해 알람을 예약하고, 알람이 울리고 나면 다음 날 일출 시각으로 **스스로 다시 예약**합니다. 한 번 켜두면 계절이 바뀌어도 계속 따라갑니다.

Figma로 디자인하고 SwiftUI로 직접 구현했습니다.

## 사용 흐름

```
첫 실행 → 위치 권한 허용 → 내 위치 기반 일출 시간 계산
   → 홈에서 내일 일출 시간 확인 → 알람 토글 ON → 예약 완료
   → 알람이 울리면 다음 날 일출 시간으로 자동 재예약 (반복)
```

## 화면

| 화면 | 설명 |
| --- | --- |
| 온보딩 | 첫 실행 시 위치 권한 요청 |
| 홈 | 내일 일출 시간 표시 · 알람 토글 · 날씨 테마 배경 |
| 기상 | 알람이 울릴 때의 화면 |
| 개인 | 일출 시간 변화 스파크라인 차트 · 할 일 목록 |
| 설정 | 일출 시각 기준 알람 오프셋 조절 (예: 일출 20분 전) |

## 이런 걸 만들었어요

- **날씨 테마 배경** — 날씨 상태에 따라 홈 화면 배경이 바뀌고, 오브가 부드럽게 움직입니다 (`WeatherThemeLibrary.swift`, `AnimatedOrbsBackground.swift`)
- **배경 밝기 대응 텍스트** — 배경이 밝아지면 텍스트 색이 자동으로 전환돼 어떤 날씨에서도 읽힙니다
- **자동 재예약** — 알람이 울린 뒤 다음 날 일출 시각을 다시 계산해 예약 (`NotificationManager.swift`, `BackgroundTaskManager.swift`)
- **디자인 토큰** — 컬러 · 타이포를 `DesignTokens.swift` 한 곳에 정의해 화면 전체에서 재사용
- **날씨 소스 교체** — WeatherKit으로 시작했다가 Open-Meteo로 옮겼습니다. 개발용 디버그 바에서 두 소스의 값을 나란히 비교하며 검증했습니다

## 기술

| | |
| --- | --- |
| UI | SwiftUI |
| 저장 | SwiftData (할 일 목록) |
| 위치 | CoreLocation |
| 알림 · 알람 | UserNotifications · AVFoundation |
| 백그라운드 | BackgroundTasks |
| 날씨 | Open-Meteo API |
| 최소 버전 | iOS 17+ |

## 실행

Xcode에서 `ui.xcodeproj`를 열고 실행합니다.

> 저장소 이름은 `riseupapp`, Xcode 프로젝트와 메인 타깃은 `ui`, 앱 표시 이름은 `Suners`입니다. 기획 단계의 이름이 그대로 남아 있는 것으로, **코드는 `ui/` 폴더**에 있습니다.

위치 권한과 알림 권한이 필요합니다. 일출 시각과 날씨는 실제 위치를 기준으로 하므로, **시뮬레이터보다 실기기에서 확인하는 것이 정확**합니다.

## 구조

```
ui/
├── Views/            # 홈 · 온보딩 · 기상 · 개인 · 설정 화면
├── Models/           # 알람 설정, 할 일 데이터 모델
├── Managers/         # 위치 · 알림 · 알람 오디오 · 백그라운드 작업
├── Services/         # 일출 계산, 날씨 조회
├── DesignTokens.swift        # 컬러 · 타이포 정의
└── WeatherThemeLibrary.swift # 날씨별 배경 테마
```
